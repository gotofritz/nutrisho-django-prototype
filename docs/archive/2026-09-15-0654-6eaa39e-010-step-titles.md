# Plan 010: Step Titles

## Status: Shipped

Tracks [issue #20](https://github.com/gotofritz/nutrisho-django-prototype/issues/20).

## Goal

Some steps are written with a heading baked into the text:

```
<u>RAGÚ</u>: Sauté the ground beef in olive oil until browned
FOR THE STOCK: soak the kombu in water overnight
```

That heading is structure, not prose, and today it is stored as part of
`step_text`. Give `Step` an optional `step_title` so the heading is its own
field — styled on render, editable on its own, and carried through YAML. A step
with no title behaves exactly as it does now.

## Decisions

**Schema.** A new optional column, `Step.step_title`
(`CharField(max_length=128, blank=True, default="")`). Stored as `""` when
absent, never `NULL`, matching the rule already applied to
`short_description`, `group_name`, `unit` and `preparation`.

**Titles carry no markup.** The `<u>` in the legacy text wrapped the title; it
was never part of it. Backfill strips the wrapper and stores `RAGÚ`, and
`_step_display.html` escapes the title and styles it with CSS. Only
`step_text` keeps going through `safe_step_html`.

**YAML.** `directions.step` items become **either** a plain string (untitled —
the shape every file uses today) **or** a mapping `{title, text}` (titled).
Export emits the mapping only when a title is set, so untitled recipes
round-trip byte-identically and the 200-odd files in `recipes_yaml/` do not
churn. Import accepts both shapes.

**Splitting rule** (`recipes/utils/step_title.py`, framework-free like
`pluralise.py`): a step text has a title when it opens with

- an inline tag wrapper — `<u>`, `<b>`, `<i>` or `<s>` — closed before a colon,
  whatever its case: `<u>RAGÚ</u>: …`; or
- an unwrapped run that is entirely upper case: `FOR THE STOCK: …`

and, in both cases, the colon is followed by whitespace and something is left
over. `Add salt: to taste` is prose, not a title, and stays whole; so does a
step that is *only* a heading, since `step_text` cannot be blank.

## TDD phases

Each cycle is **red → green → refactor**. Run `task qa` before the PR; keep
coverage ≥ 95%.

- **1** `Step.step_title` + migration `0015`.
  - Tests: a step saves without a title and reads back `""`; a title persists;
    `max_length` is 128.
- **2** `split_step_title(text) -> (title, remainder)` in
  `recipes/utils/step_title.py`.
  - Tests: `<u>RAGÚ</u>: x` → `("RAGÚ", "x")`; each of `<b>/<i>/<s>`; bare
    `FOR THE STOCK: x`; `Add salt: to taste` unchanged; `MIX 1:1 ratio`
    unchanged (no space after the colon); a heading-only step unchanged; a
    title longer than 128 chars unchanged; leading whitespace tolerated.
- **3** Render. `_step_display.html` and the clean-up tool's
  `_recipe_preview.html` show the title before the text when set, escaped, in
  its own `.step-title` element; CSS in `style.css` (`print.css` carries no
  step rules of its own).
  - Tests: title shown when set, on the recipe page and in the preview; no
    `.step-title` element when blank; HTML in a title is escaped; the text
    still renders its allowed tags.
- **4** Edit. `StepForm` gains `step_title` (text input, placeholder
  `Title (optional)`); `recipe_step_save` adds it to `update_fields`.
  - Tests: the edit form carries the current title; save persists a new title;
    clearing it stores `""`; create accepts a title; a step with no title still
    saves.
- **5** Export. `recipe_to_dict` writes `{title, text}` for a titled step and a
  plain string otherwise.
  - Tests: untitled export is unchanged; titled export is a mapping; a full
    export → import round-trip preserves both.
- **6** Import. `batch_load_yaml_recipes` accepts a string or a
  `{title, text}` mapping, cleaning both fields; a mapping missing `text`
  is a `CommandError` naming the file.
  - Tests: legacy string import unchanged; mapping import sets both fields;
    `title` omitted or `null` → `""`; missing `text` errors.
- **7** Backfill. `scripts/backfill_step_titles.py` — throwaway driver over the
  phase-2 helper, with `--dry-run`. Two modes: DB rows (default) and
  `--yaml recipes_yaml/`, which rewrites the seed files so `task filldb` does
  not undo the backfill, and un-shouts an all-caps heading into sentence case
  (`sentence_case_heading`) — including on a re-run over steps an earlier run
  already split. Ran over `recipes_yaml/`: 24 steps in 10 files.
- **8** Docs: `docs/initial-context.md` (the new field, the YAML step shape) and
  `README.md` (titles in the editing section). Archive this plan.

## Out of scope

- Titles on anything but steps.
- Grouping steps under a shared heading (a title stays attached to one step).
- Markup inside a title.
